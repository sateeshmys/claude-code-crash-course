## 2025-05-18 - HeroTerminal Re-render Reduction via State Colocation and CSS Keyframes
**Learning:** High-frequency UI updates (like typing text effects and cursor blinking in hero sections) cause unnecessary re-renders of large static parent components if state is maintained in the top-level component. Replacing `useState` timers for visual effects with CSS keyframe animations (`@keyframes blink`) and colocating typing animation state into a dedicated child component (`TerminalMockup`) prevents parent component re-renders completely during animation cycles.
**Action:** For visual timers (e.g. blinking cursors, pulsing lights), always use pure CSS keyframe animations instead of React `useState` intervals. When animating dynamic sub-regions of a page, colocate the animation state within an isolated sub-component.
