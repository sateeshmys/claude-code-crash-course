## 2026-05-20 - [Isolating high-frequency state updates]
**Learning:** In the `HeroTerminal` component, a 100ms typing interval and a 530ms cursor blink interval were triggering full component re-renders. This is particularly expensive when the component contains complex SVGs, static content, and background patterns. By isolating the typing logic into a memoized sub-component and replacing the cursor state with a CSS animation, we reduced the main component's re-renders from ~80 to nearly zero during the animation.
**Action:** Always isolate high-frequency state updates (typing effects, timers, frequent animations) into dedicated memoized sub-components. Prefer CSS animations over React state for simple visual toggles like blinking cursors to reduce main thread activity and React reconciliation overhead.
