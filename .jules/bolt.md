## 2025-12-25 - React Component State Isolation and CSS Animation Optimization for Terminal Simulation
**Learning:** High-frequency layout-affecting state updates (such as typing simulation character-by-character updates and cursor blinking) triggered over 90+ parent component re-renders inside `HeroTerminal` within a 10-second window. By moving the visual blinking cursor animation entirely to high-performance pure CSS keyframes (`animate-blink` using `step-end`) and isolating the typing animation state into a local subcomponent (`TerminalMockup`), we completely eliminated redundant parent re-renders. This reduced parent `HeroTerminal` component re-renders from ~98 down to just 2 (initial mount and hydration), improving CPU efficiency and rendering performance dramatically.
**Action:** Always isolate interactive simulation animations or high-frequency state updates into dedicated, lightweight local subcomponents, and replace javascript-interval-based visual toggles (like cursor blinking) with hardware-accelerated pure CSS animations.
