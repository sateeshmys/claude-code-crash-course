## 2025-08-06 - Reducing High-Frequency React Re-renders in Static Hero Components
**Learning:** High-frequency UI changes, such as blinking cursors (every 530ms) or typing animations (every 100ms) in terminal simulators, cause the entire parent React component (and its sibling layout/content subtrees) to re-render constantly. Replacing React state for visual-only blinking behaviors with CSS animations (e.g., using pure keyframes with `step-end`) and colocating the typing state into a specialized child component (e.g., `TerminalMockup`) completely prevents parent re-renders.
**Action:** Always isolate visual animations and high-frequency UI states into self-contained sub-components or leverage pure CSS transitions/animations instead of React `useState` to minimize render churn on the parent layout tree.
