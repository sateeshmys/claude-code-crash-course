## 2026-08-08 - React Terminal High-Frequency Visual Optimization
**Learning:** In terminal visual components that simulate real-time typing or custom cursors, using React state (`useState` + `setInterval`) for cursor blinking triggers infinite components' render cycles even after typing animations terminate. Isolating high-frequency states into specialized leaf components prevents heavy parent trees with complex background SVGs, grids, and CTA structures from re-rendering, while replacing JavaScript-based visual intervals with custom CSS keyframe animations completely eliminates rendering overhead after completion.
**Action:** Always colocate typing simulation states into sub-components and leverage pure CSS animations (like `.animate-blink` with `step-end`) for infinite cursor blink states to drastically optimize rendering cycles from ~98 down to only 2 (initial mount and hydration) in Next.js/React environments.
